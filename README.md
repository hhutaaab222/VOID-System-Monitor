# VOID System Monitor

A lightweight Linux system monitor written in Python.

## Features

- System information
- CPU information
- CPU usage monitoring
- RAM usage monitoring
- Neon terminal interface

## Requirements

- Python 3
- psutil

## Installation

```bash
git clone https://github.com/ТВОЙ_НИК/VOID-System-Monitor.git
cd VOID-System-Monitor
pip install psutil
python3 main.py
